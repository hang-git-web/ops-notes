# 01 必会：常用命令、权限与用户

> **应届生级别的范围**：会常用命令、说清 rwx 的含义、知道用户和 sudo。
> **不需要**：特殊权限细节、ACL、inode 原理（那些在 `进阶版/`）。

## 一、常用命令（**背分类，不背全集**）

| 类别 | 命令 | 一句话 |
| --- | --- | --- |
| 看目录 | `ls -lh` / `ls -a` / `pwd` | 详情 / 含隐藏文件 / 当前路径 |
| 切目录 | `cd /etc` / `cd -` / `cd ~` | 进入 / 回上个目录 / 回家目录 |
| 建删 | `mkdir -p a/b` / `rm -f` / `rm -rf` | 递归建目录 / 删文件 / **删目录（不可恢复）** |
| 复制移动 | `cp -r dir1 dir2` / `mv a b` | 复制目录要加 `-r` / 移动或重命名 |
| 看内容 | `cat` / `less` / `head` / `tail -f` | 大文件用 less；**`tail -f` 实时跟日志** |
| 找文件 | `find /var/log -name "*.log"` | **按文件名/属性找** |
| 找内容 | `grep -rn "error" /var/log` | **在文件内容里找** |
| 打包 | `tar -czvf b.tar.gz /data` / `tar -xvf` | 打包压缩 / 解压 |
| 看空间 | `df -h` / `du -sh /var` | 分区容量 / 目录占用 |
| 看进程 | `ps aux` / `top` | 快照 / 实时 |
| 网络 | `ping` / `ss -tlnp` / `curl` | 连通 / 监听端口 / 测接口 |
| 编辑 | `vim` | `i` 插入、`Esc`、`:wq` 保存退出、`:q!` 强退 |

### ⚠️ 三个最容易被问错的

| 容易混 | 正确答案 |
| --- | --- |
| `find` vs `grep` | `find` **按文件名/属性找文件**；`grep` **在文件内容里找文字** |
| `df` vs `du` | `df` 看**分区**还剩多少；`du` 看**目录/文件**占了多少 |
| `tail -f` vs `cat` | `-f` 是**持续跟踪新内容**，看日志用它；`cat` 是一次性全打出来 |

### 面试可能这么问

**Q：怎么查看一个文件的内容？**
A：小文件用 `cat`，大文件用 `less`（可以上下翻、`/` 搜索）；只看头部用 `head`，实时看日志用 `tail -f`。

**Q：怎么在日志里找报错？**
A：`grep -n "ERROR" app.log`（`-n` 显示行号）；想看得更全用 `grep -C 3`，能显示错误前后各 3 行。

**Q：怎么找出 /var/log 下 7 天前的日志？**
A：`find /var/log -name "*.log" -mtime +7`。

## 二、权限：`rwx` 对文件和目录含义不同（★ 高频）

### 2.1 三种角色

```text
-rw-r--r--  1 root root  1234 Aug 26 10:00 a.txt
 │└┬┘└┬┘└┬┘
 │ │  │  └── 其他人（others）
 │ │  └───── 所属组（group）
 │ └──────── 文件所有者（user）
 └────────── 类型：- 文件、d 目录、l 链接
```

### 2.2 核心考点：rwx 对"文件"和"目录"完全不同

| 权限 | 对**文件** | 对**目录** |
| --- | --- | --- |
| `r` | 读文件内容 | **列出目录里的文件名**（`ls`）|
| `w` | 改文件内容 | **在目录里创建/删除/改名文件** |
| `x` | 执行文件 | **进入目录**（`cd`）|

> **一句话**：**文件的 rwx 管"内容"，目录的 rwx 管"名单和进出"。**

**两个常考的推论**（能说出来就是加分）：

1. **能不能删一个文件，看的是"目录的 w 权限"，不是文件自己的权限**（删除是"从目录里移除一个名字"）。
2. **目录有 r 没 x**：能 `ls` 看到文件名，但 `cd` 不进去。

### 2.3 改权限的两个写法

```bash
# 字母法
chmod u+x a.sh          # 给所有者加执行权限
chmod o-r a.txt         # 去掉其他人的读权限
chmod a+r a.txt         # 所有人都能读

# 数字法（r=4 w=2 x=1，三位分别对应 所有者/组/其他人）
chmod 755 a.sh          # rwxr-xr-x  ← 目录、可执行脚本
chmod 644 a.txt         # rw-r--r--  ← 普通文件、配置文件
chmod 600 key.pem       # rw-------  ← 私钥、密码文件
chmod 777 a.txt         # 谁都能读写执行 ← ★ 生产禁止
```

| 数字 | 权限 | 用在哪 |
| --- | --- | --- |
| **755** | rwxr-xr-x | 目录、脚本 |
| **644** | rw-r--r-- | 普通文件、配置 |
| 600 | rw------- | 私钥、口令文件 |
| 777 | rwxrwxrwx | ❌ 生产禁止 |

### 2.4 改属主属组

```bash
chown tom a.txt              # 改所有者
chown tom:dev a.txt          # 同时改所有者和组
chown -R www:www /data/www   # 递归改（部署网站后常用）

chgrp dev a.txt              # 只改所属组
```

### 2.5 umask（知道概念即可）

```text
新建文件/目录的权限 = 最大权限 − umask
· 目录最大 777，文件最大 666（文件默认不给 x）
· umask = 022 时：目录 777−022 = 755，文件 666−022 = 644
```

`umask` 查看当前值，`umask 027` 临时修改。

### 2.6 特殊权限（**只需知道名字和例子**）

| 权限 | 一句话 |
| --- | --- |
| **SUID** | 执行时临时获得文件所有者的权限，例如 `/usr/bin/passwd`（普通用户也能改自己的密码）|
| **SGID** | 执行时获得组权限；用在目录上则新建文件继承目录的组 |
| **Sticky** | 目录内的文件只有属主能删，例如 `/tmp`（人人可写但不能删别人的）|

> 面试问"SUID 是什么"，答出 **"passwd 命令用它来让普通用户改密码"** 就够了。

## 三、用户与用户组

```bash
useradd -m -s /bin/bash tom      # 建用户（-m 建家目录）
passwd tom                        # 设置密码
usermod -aG dev tom               # 追加到 dev 组（★ 少写 -a 会覆盖原有组）
id tom                            # 查看用户的 UID/GID 和所属组
userdel -r tom                    # 删除用户（-r 连家目录一起删）
```

### sudo 与 wheel 组

```bash
usermod -aG wheel tom             # CentOS：加入 wheel 组后 tom 才能用 sudo
# Ubuntu 上加的是 sudo 组
```

### 四个关键文件（知道作用即可）

| 文件 | 内容 |
| --- | --- |
| `/etc/passwd` | 用户信息（所有人可读）|
| `/etc/shadow` | **密码密文**（只有 root 能读）|
| `/etc/group` | 组信息 |
| `/etc/sudoers` | sudo 授权规则（改完用 `visudo` 校验）|

### 面试可能这么问

**Q：为什么普通用户执行 `passwd` 能改 `/etc/shadow`？**
A：因为 `passwd` 带 **SUID** 权限，执行的那一瞬间进程以 **root 身份**运行，所以能写 shadow；改完立即恢复成普通用户。

**Q：怎么把一个用户加入 sudo？**
A：`usermod -aG wheel 用户名`（CentOS；Ubuntu 是 sudo 组）。
