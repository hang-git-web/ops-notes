## 二、这份面经在考什么：4 个信号

```text
信号 1  全简答、无手撕 → 考"能不能用结构说清原理"，不考你会不会敲命令
信号 2  明显往内核机制走 → 启动流程、信号、缺页中断、内存映射、IPC 七种方式
信号 3  有纯步骤题（扩盘 9 条命令） → 考"这个操作你到底做过没有"
信号 4  有概念辨析题（并发/并行、MB/Mb） → 考基础有没有常识漏洞
```

**再加一条 AI 面试的特点**：它会**顺着你的回答往下追问**。所以每题都要准备"第二层"：

| 你答了 | 大概率被追问 |
| --- | --- |
| 硬链接/软链接 | inode 是什么、为什么硬链接不能跨文件系统 → `12` |
| Ctrl+Z 挂起 | 挂起后进程是什么状态、怎么恢复 → `11` |
| kill -9 | 为什么有时候 -9 也杀不掉 → `11` |
| sy 高 | 那上下文切换怎么看 → `16` |
| OOM 是内存不够 | 内核按什么杀进程、overcommit 是什么 → `14` |
| 缺页中断 | major 和 minor 缺页的区别 → `14` |
| 共享内存 | 为什么它最快、怎么同步 → `15` |
