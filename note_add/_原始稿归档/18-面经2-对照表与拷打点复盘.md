## 二、复盘：为什么"答了"还被拷打

### 拷打点 1：报名词，不解释本质（第 3 题）

```text
他答："b 块设备（硬盘就属于块设备，这里也被拷打）、c 字符设备（比如终端，同样被拷打）"
面试官想要的：块设备 = 按固定大小的块随机读写、可以挂载文件系统、有内核缓冲；
              字符设备 = 按字节流顺序读写、一般不经过缓冲、不能挂载。
              并且各举一个例子：/dev/sda、/dev/sdb1 是块设备；/dev/tty、/dev/null、/dev/zero 是字符设备。
```

> **教训**：每种类型**至少带一个例子 + 一句区别**，不要只念字母对应的中文。
> 详见 `12-补充-文件类型与inode.md`。

### 拷打点 2：步骤题漏关键字（第 2 题）

```text
他答："lsblk 看盘、分区、（这里漏了！）、格式化、挂载、写 fstab"
——他自己写"漏说了分区，被拷打了"
```

> **因为扩盘这类题是"清单题"，面试官会逐项核对**，漏掉一步就等于没做过。
> **口诀**：**识别 → 分区 → 刷新（partprobe）→ 格式化 → 挂载 → fstab → `mount -a` 验证。**
> 加分关键词：`partprobe`、`blkid` 取 **UUID**、加 **`nofail`**、`mount -a` 验证。详见 `13`。

### 拷打点 3：只会一种工具、一种说法（第 5 题）

```text
他答出了 -lntp 的含义，但没主动补：怎么看连接（-ant）、怎么过滤（state established）、
替代命令（lsof -i :80、netstat -lntp）、以及"80 端口的连接"到底问的是哪一种。
```

> **教训**：每个命令准备"**一个主用 + 一个替代 + 一个过滤条件**"三件套。
> ```bash
> ss -lntp                      # 主用：谁在监听
> netstat -lntp / lsof -i :80   # 替代：老写法 / 直接看是哪个进程占用
> ss -tn '( dport = :80 )'     # 过滤：只看连到 80 的连接
> ```

### 拷打点 4：边界场景答不出（第 1 题）

```text
bash / source 都能答，题目里加一个 exec 就蒙了。
根源：没记住 exec 的本质是"不新建进程，用新程序覆盖当前进程映像"。
```

> 记住这句：**"source 是借你的壳干活，bash 是另开一个壳干活，exec 是把你的壳换掉。"**
> 详见 `10-补充-Shell与环境变量.md` 的 2.6（含四态对比表）。

## 四、答题模板：4 句话说完一个概念题（★ 照着套）

```text
① 定义     它是什么（一句话 + 类比）
② 本质     背后机制是什么、为什么需要它
③ 怎么用   命令/参数/例子（至少给一条真实命令）
④ 注意点   坑、上限、容易混的概念区分
```

**用第 4 题（什么是软链接）示范**：

```text
① 定义：软链接是一个"快捷方式"文件，里面存的是目标文件的路径。
② 本质：它和目标文件是两个不同的 inode；内核访问时按存的路径重新解析，
        所以能跨文件系统、也能指向目录，但目标删了它就变成断链。
③ 怎么用：ln -s /opt/app/v1.2 /opt/app/current —— 发布切版本、回滚都靠它。
④ 注意点：软链接自己的权限位没意义（永远 lrwxrwxrwx），看的是目标文件权限；
          覆盖已有链接要 ln -sf；用相对路径创建时是相对链接所在目录解析，移动链接会断。
```

> 按这个模板答，任何一道概念题都能撑满 40 秒，而且面试官的追问点你都已经提前堵住了。
