# 单服务器多站点部署(同端口、多域名、独立前后端)

> 背景:某公司需要在一台服务器上部署 2 个 Web 站点,端口相同、域名不同,且两个站点使用**独立的前端页面**和**独立的数据库**。
> 参考:《Nginx 虚拟主机配置实战(案例一)》

---

## 一、目标

| 需求 | 说明 |
| --- | --- |
| 同一台服务器 | 一个 IP |
| 同一个端口 | 都使用 80 |
| 不同域名 | www.site1.com / www.site2.com |
| 独立前端 | 各自独立的站点目录 |
| 独立数据库 | 各自独立的库和账号 |

访问效果:

- 访问 `www.site1.com` → 站点 1 的页面,读写 `site1` 库
- 访问 `www.site2.com` → 站点 2 的页面,读写 `site2` 库

## 二、实现原理

Nginx 的虚拟主机(Virtual Host)通过请求头里的 `Host` 与 `server_name` 匹配,决定请求进入哪个 `server` 块。

```text
浏览器请求 Host: www.site1.com
        ↓
Nginx(80 端口)
        ├── server_name www.site1.com → root /data/www/site1 → 数据库 site1
        └── server_name www.site2.com → root /data/www/site2 → 数据库 site2
```

要点:**端口相同不会冲突**,区分站点靠域名,Web 站点靠 `server_name`,数据库靠各自的库与账号。

## 三、部署规划

| 项目 | 站点 1 | 站点 2 |
| --- | --- | --- |
| 域名 | www.site1.com | www.site2.com |
| 站点目录 | /data/www/site1 | /data/www/site2 |
| Nginx 配置 | /etc/nginx/conf.d/site1.conf | /etc/nginx/conf.d/site2.conf |
| 数据库名 | db_site1 | db_site2 |
| 数据库账号 | user_site1 | user_site2 |
| 数据库密码 | Site1@123456 | Site2@123456 |

## 四、实施步骤

### 1. 创建两个站点目录

```bash
mkdir -p /data/www/site1 /data/www/site2
```

### 2. 部署两套源码

```bash
cp -a /data/upload/site1/. /data/www/site1/
cp -a /data/upload/site2/. /data/www/site2/
```

### 3. 设置属主与 SELinux 标签

```bash
chown -R nginx:nginx /data/www/site1 /data/www/site2
chmod -R 755 /data/www/site1 /data/www/site2
chcon -Rt httpd_sys_content_t /data/www
```

### 4. 创建两个独立数据库和账号

```bash
mysql -uroot -p
```

```sql
-- 站点 1
CREATE DATABASE db_site1 DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
CREATE USER 'user_site1'@'localhost' IDENTIFIED WITH mysql_native_password BY 'Site1@123456';
GRANT ALL PRIVILEGES ON db_site1.* TO 'user_site1'@'localhost';

-- 站点 2
CREATE DATABASE db_site2 DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
CREATE USER 'user_site2'@'localhost' IDENTIFIED WITH mysql_native_password BY 'Site2@123456';
GRANT ALL PRIVILEGES ON db_site2.* TO 'user_site2'@'localhost';

FLUSH PRIVILEGES;
EXIT;
```

导入各自的 SQL:

```bash
mysql -uuser_site1 -p --default-character-set=utf8mb4 db_site1 < /data/upload/site1.sql
mysql -uuser_site2 -p --default-character-set=utf8mb4 db_site2 < /data/upload/site2.sql
```

### 5. 修改两套源码的数据库配置

站点 1 的配置文件:

```php
define('DB_HOST', '127.0.0.1');
define('DB_USER', 'user_site1');
define('DB_PASS', 'Site1@123456');
define('DB_NAME', 'db_site1');
```

站点 2 的配置文件:

```php
define('DB_HOST', '127.0.0.1');
define('DB_USER', 'user_site2');
define('DB_PASS', 'Site2@123456');
define('DB_NAME', 'db_site2');
```

### 6. 创建两个 Nginx 站点配置

```bash
vim /etc/nginx/conf.d/site1.conf
```

```nginx
server {
    listen       80;
    server_name  www.site1.com;

    root   /data/www/site1;
    index  index.php index.html;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass   127.0.0.1:9000;
        fastcgi_index  index.php;
        fastcgi_param  SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include        fastcgi_params;
    }

    access_log /var/log/nginx/site1_access.log;
    error_log  /var/log/nginx/site1_error.log;
}
```

```bash
vim /etc/nginx/conf.d/site2.conf
```

```nginx
server {
    listen       80;
    server_name  www.site2.com;

    root   /data/www/site2;
    index  index.php index.html;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass   127.0.0.1:9000;
        fastcgi_index  index.php;
        fastcgi_param  SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include        fastcgi_params;
    }

    access_log /var/log/nginx/site2_access.log;
    error_log  /var/log/nginx/site2_error.log;
}
```

### 7. 配置域名解析

实验环境(修改 hosts):

```bash
echo "服务器IP www.site1.com www.site2.com" >> /etc/hosts
```

生产环境:在域名服务商处分别为两个域名添加 A 记录,指向同一个服务器 IP。

### 8. 检查并加载配置

```bash
nginx -t
systemctl reload nginx
systemctl restart php-fpm
ss -nltp | grep -E ':80|:9000'
```

## 五、验证

```bash
curl http://www.site1.com
curl http://www.site2.com
```

验证清单:

- 两个域名返回各自站点的页面,互不干扰
- 站点 1 写入的数据只出现在 `db_site1`
- 站点 2 写入的数据只出现在 `db_site2`
- 各自的访问日志、错误日志分开记录

也可以用 Host 头直接验证(不依赖域名解析):

```bash
curl -H "Host: www.site1.com" http://服务器IP
curl -H "Host: www.site2.com" http://服务器IP
```

## 六、关键点

1. **同端口多站点靠域名区分**:Nginx 按 `server_name` 匹配,数据库按库名区分
2. **前端隔离**:目录分开 + 权限归属 nginx,SELinux 标签正确
3. **数据库隔离**:一库一账号,只授权自己的库(最小权限原则),避免一站出错影响另一站
4. **日志隔离**:两个站点独立的 access/error 日志,便于单独排查
5. **兜底站点**:建议保留一个 `default_server`,防止未匹配的域名落到随机站点
