# 官网 LNMP 部署实施手册(云主机上线实战)

## 〇、先定好参数(后面所有步骤都引用这些值)

| 参数 | 示例值 | 说明 |
| --- | --- | --- |
| 服务器公网 IP | `你的云主机公网IP` | 云控制台查看 |
| 域名 | `www.example.com` | 若未备案,先用 IP 访问 |
| 源码上传目录 | `/data/upload` | Xftp 传到这里 |
| SQL 文件 | `/data/upload/mysite.sql` | 服务商提供 |
| 站点根目录 | `/data/www/mysite` | 与 Nginx 配置的 `root` 一致 |
| 数据库名 | `mysite` | 自定义 |
| 数据库用户 | `siteadmin` | 给网站程序用,不用 root |
| 数据库密码 | `Site@123456` | 8 位以上,含大小写+数字+符号 |
| MySQL root 密码 | `Root@123456` | 仅本机管理用 |

> 记录版本,方便排错:`nginx -v`、`php -v`、`mysql --version`

## 一、安装工具与中间件(注意版本冲突)

### 1. 基础工具

```bash
yum install -y vim tar net-tools wget
```

### 2. 中间件

题面给的命令在 **CentOS 7** 上会有一个坑:**默认源里没有 `mysql-server`**,而且 CentOS 7 自带 PHP 只有 5.4。所以分两种情况:

**方案 A:CentOS 7 + MySQL 8 官方源(推荐,和后面 PHP 配置对应)**

```bash
# 先加 MySQL 官方 yum 源
rpm -Uvh https://dev.mysql.com/get/mysql80-community-release-el7-3.noarch.rpm

# 安装(如遇 GPG 报错,练习环境可加 --nogpgcheck)
yum install -y nginx php php-fpm mysql-community-server php-mysqlnd
```

**方案 B:直接装 MariaDB(CentOS 7 自带,最省事)**

```bash
yum install -y nginx php php-fpm mariadb-server mariadb php-mysqlnd
```


> **版本冲突提示(重点)**
> 1. 服务名不同:MySQL 8 是 `mysqld`,MariaDB 是 `mariadb`,Ubuntu 是 `mysql`
> 2. PHP 5.4(CentOS 7 自带)连 MySQL 8 会出现两组认证/字符集报错,处理办法见文末“版本冲突专项”
> 3. PHP-FPM 监听方式不同:CentOS 7 默认 `127.0.0.1:9000`(TCP),Ubuntu 默认是 unix socket,Nginx 的 `fastcgi_pass` 必须和它一致

## 二、启动数据库并设置 root 密码

### 1. 启动服务

```bash
systemctl start mysqld
systemctl enable mysqld
systemctl status mysqld
```

> 用 MariaDB 就把 `mysqld` 换成 `mariadb`。

### 2. 设置 root 密码

**MySQL 8(有临时密码)**

```bash
# 从日志里找临时密码
grep 'temporary password' /var/log/mysqld.log

mysql -uroot -p
```

```sql
ALTER USER 'root'@'localhost' IDENTIFIED BY 'Root@123456';
FLUSH PRIVILEGES;
EXIT;
```

**MariaDB(无临时密码)**

```bash
mysqladmin -u root password 'Root@123456'
# 或者交互式加固
mysql_secure_installation
```

## 三、创建数据库、创建管理员用户并授权

```bash
mysql -uroot -p
```

```sql
-- 1. 创建数据库(utf8mb4 才能存中文和 emoji)
CREATE DATABASE mysite DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;

-- 2. 创建网站专用账号,% 表示允许从任何 IP 登录
CREATE USER 'siteadmin'@'%' IDENTIFIED WITH mysql_native_password BY 'Site@123456';

-- 3. 只把新数据库的权限授予该用户(最小权限原则)
GRANT ALL PRIVILEGES ON mysite.* TO 'siteadmin'@'%';

-- 4. 刷新权限并确认
FLUSH PRIVILEGES;
SELECT user, host, plugin FROM mysql.user WHERE user = 'siteadmin';
SHOW DATABASES;
EXIT;
```

**安全提示**

- `'%'` 允许任意 IP 连接。网站程序和数据库在同一台机器时,建议用 `'localhost'` 和 `'127.0.0.1'`;只有数据库单独部署时才用 `%`
- 用了 `%` 就必须靠防火墙/Security Group 限制 3306 端口,不要对公网开放
- 若必须远程连接,还要检查 `bind-address`(MariaDB 默认只监听 127.0.0.1)

## 四、用 Xftp 上传源码与 SQL

1. Xftp 新建连接:主机填服务器公网 IP,端口 22,协议 SFTP,用户名 `root`,密码为服务器密码
2. 在服务器上先建好目录:

```bash
mkdir -p /data/upload
```

3. 把源码压缩包和 `mysite.sql` 拖到 `/data/upload`

4. 回到终端解压:

```bash
cd /data/upload
yum install -y unzip          # 如果上传的是 zip
unzip 源码.zip -d /data/upload/src
# 或者
tar -zxvf 源码.tar.gz -C /data/upload/src

ls -l /data/upload
```

## 五、导入 SQL 到数据库

```bash
# 方式一:直接导入(推荐,指定 utf8mb4 防止中文乱码)
mysql -uroot -p --default-character-set=utf8mb4 mysite < /data/upload/mysite.sql

# 方式二:先进入 mysql 再 source
mysql -uroot -p
```

```sql
USE mysite;
SOURCE /data/upload/mysite.sql;
```

验证导入结果:

```bash
mysql -uroot -p -e "USE mysite; SHOW TABLES;"
mysql -uroot -p -e "USE mysite; SELECT COUNT(*) FROM 某张表;"
```

> 如果 SQL 文件里本身带 `CREATE DATABASE` 语句,上面命令里的 `mysite` 可以省略,直接 `mysql -uroot -p < xxx.sql`。
> 导入报 `Unknown collation: utf8mb4_0900_ai_ci` 等错误,说明导出环境比导入环境新,处理见文末专项。

## 六、部署站点代码并配置 Nginx

### 1. 把代码放到站点根目录

```bash
mkdir -p /data/www/mysite
cp -a /data/upload/src/. /data/www/mysite/
ls -l /data/www/mysite
```

### 2. 设置属主与权限

```bash
chown -R nginx:nginx /data/www/mysite
chmod -R 755 /data/www/mysite
```

> 题面要求“授予 777 权限”:`chmod -R 777 /data/www/mysite` 可以用,但**安全性很差**——任何用户都能改写网站文件,等于给入侵者留了后门。生产环境建议 `755` 目录 + `644` 文件 + `chown nginx`,只对确实需要写入的目录(如 `runtime/`、`uploads/`)单独放宽:
> ```bash
> chmod -R 777 /data/www/mysite/runtime /data/www/mysite/uploads
> ```

### 3. 处理 SELinux(否则 403)

```bash
chcon -Rt httpd_sys_content_t /data/www/mysite
```

### 4. 创建 Nginx 站点配置

```bash
vim /etc/nginx/conf.d/mysite.conf
```

**通用 PHP 站点配置**

```nginx
server {
    listen       80;
    server_name  www.example.com 你的服务器IP;

    root   /data/www/mysite;
    index  index.php index.html index.htm;

    # 静态文件优先,找不到再交给 index.php(适合 ThinkPHP/Laravel/大部分 CMS)
    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass   127.0.0.1:9000;
        fastcgi_index  index.php;
        fastcgi_param  SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include        fastcgi_params;
    }

    # 禁止访问敏感文件
    location ~ /\.(git|env|htaccess) {
        deny all;
    }

    access_log /var/log/nginx/mysite_access.log;
    error_log  /var/log/nginx/mysite_error.log;
}
```

> Ubuntu 上 PHP-FPM 用 socket,`fastcgi_pass` 要改成类似:
> `fastcgi_pass unix:/run/php/php8.1-fpm.sock;`(版本号按实际)

检查语法:

```bash
nginx -t
```

出现 `syntax is ok` + `test is successful` 才继续。

## 七、配置 PHP-FPM 并启动服务

### 1. 让 PHP-FPM 以 nginx 用户运行

```bash
sed -i 's/^user = apache/user = nginx/; s/^group = apache/group = nginx/' /etc/php-fpm.d/www.conf
grep -E '^(user|group|listen)' /etc/php-fpm.d/www.conf
```

预期:

```text
user = nginx
group = nginx
listen = 127.0.0.1:9000
```

### 2. 启动 Nginx 与 PHP-FPM

```bash
systemctl start nginx
systemctl enable nginx
systemctl start php-fpm
systemctl enable php-fpm
```

### 3. 检查端口

```bash
ss -nltp | grep -E ':80|:9000|:3306'
```

预期:Nginx 监听 80、PHP-FPM 监听 9000、MySQL 监听 3306。

### 4. 放行 SELinux 网络访问与防火墙

```bash
# SELinux 允许 Nginx 连接 PHP-FPM/后端
setsebool -P httpd_can_network_connect 1

# 防火墙放行 HTTP/HTTPS(云主机还要在安全组里放行 80/443)
firewall-cmd --permanent --add-service=http
firewall-cmd --permanent --add-service=https
firewall-cmd --reload
```

## 八、修改源码中的数据库配置

先找到数据库配置文件:

```bash
cd /data/www/mysite
grep -rn "DB_HOST\|db_host\|mysqli_connect\|password" --include="*.php" . | head -20
```

常见位置:`config.php`、`config/database.php`、`config/db.php`、`application/database.php`、`.env`

**原生 PHP 写法**

```php
define('DB_HOST', '127.0.0.1');
define('DB_USER', 'siteadmin');
define('DB_PASS', 'Site@123456');
define('DB_NAME', 'mysite');
```

**ThinkPHP 写法(config/database.php)**

```php
return [
    'type'     => 'mysql',
    'hostname' => '127.0.0.1',
    'database' => 'mysite',
    'username' => 'siteadmin',
    'password' => 'Site@123456',
    'hostport' => '3306',
    'charset'  => 'utf8mb4',
];
```

**Laravel 写法(.env)**

```env
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=mysite
DB_USERNAME=siteadmin
DB_PASSWORD=Site@123456
```

要点:

- 数据库和网站在同一台机器时,主机写 `127.0.0.1`,不要写公网 IP
- 密码含 `$`、`#`、`&` 等特殊字符时,注意配置文件里的引号转义
- 有些源码还会写死域名和路径,一并全局搜索替换:

```bash
grep -rn "http://旧域名\|/var/www/html" --include="*.php" --include="*.html" . | head
```

改完清理缓存(如果源码有缓存目录):

```bash
systemctl reload nginx
systemctl restart php-fpm
rm -rf /data/www/mysite/runtime/* 2>/dev/null
```

## 十、域名解析与备案

1. 在域名服务商处添加 A 记录,把 `www.example.com` 指向云主机公网 IP
2. 国内云主机(阿里云/腾讯云等)上的网站,**域名必须先完成 ICP 备案**才能通过 80/443 提供 Web 服务
3. 备案期间可以:
    - 直接用公网 IP 访问测试
    - 或用非 80 端口临时访问,如 `http://IP:8080`(记得在配置里改 `listen` 并放行端口)
4. 备案通过后,把 Nginx 的 `server_name` 改成正式域名即可

## 十一、版本冲突与常见坑(专项)

### 1. `yum install mysql-server` 报没有可用软件包

CentOS 7 默认源里没有,改用 MySQL 官方源(`mysql-community-server`)或 MariaDB(`mariadb-server`)。

### 2. PHP 连 MySQL 报 `Server sent charset unknown to the client`

原因:MySQL 8 默认排序规则 `utf8mb4_0900_ai_ci` 太新,老 PHP 不认识。

```bash
sed -i '/^\[mysqld\]/a character-set-server=utf8mb4\ncollation-server=utf8mb4_general_ci' /etc/my.cnf
systemctl restart mysqld
```

### 3. PHP 报 `authentication method unknown ... caching_sha2_password`

原因:MySQL 8 默认认证插件太新。

```bash
# 账号层:指定老插件
CREATE USER 'siteadmin'@'127.0.0.1' IDENTIFIED WITH mysql_native_password BY 'Site@123456';

# 服务器层:默认认证插件也改成老插件
sed -i '/^\[mysqld\]/a default-authentication-plugin=mysql_native_password' /etc/my.cnf
systemctl restart mysqld
```

### 4. 导入 SQL 报字符集/排序规则错误

```bash
mysql -uroot -p --default-character-set=utf8mb4 mysite < mysite.sql
```

如报 `Unknown collation: utf8mb4_0900_ai_ci`,用文本编辑器把 SQL 文件里的 `utf8mb4_0900_ai_ci` 全部替换为 `utf8mb4_general_ci`,再导入。

### 5. 访问网站 403 Forbidden

文件存在却不让读,基本是 SELinux:

```bash
chcon -Rt httpd_sys_content_t /data/www/mysite
systemctl reload nginx
```

### 6. 访问 .php 出现 502 Bad Gateway

Nginx 连不上 PHP-FPM,排查顺序:

```bash
systemctl status php-fpm          # 服务是否运行
ss -nltp | grep 9000              # 端口是否监听
tail -n 20 /var/log/nginx/error.log
```

看到 `connect() failed (13: Permission denied)` 就执行 `setsebool -P httpd_can_network_connect 1`。

### 7. 页面 500 或空白,看不到报错

PHP 致命错误被隐藏了,用命令行直接跑脚本看真实报错:

```bash
php /data/www/mysite/index.php
tail -n 20 /var/log/php-fpm/error.log
```

### 8. Apache 的 .htaccess 重写规则在 Nginx 不生效

Nginx 不支持 `.htaccess`。把重写规则改写进站点的 `location` 里,最常见的就是:

```nginx
location / {
    try_files $uri $uri/ /index.php?$query_string;
}
```

### 9. 后台上传大文件失败

调整 PHP 限制并重启 PHP-FPM:

```bash
sed -i 's/^upload_max_filesize.*/upload_max_filesize = 50M/' /etc/php.ini
sed -i 's/^post_max_size.*/post_max_size = 50M/' /etc/php.ini
systemctl restart php-fpm
```
