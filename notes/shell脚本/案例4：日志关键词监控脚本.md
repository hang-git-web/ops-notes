# SSH 登录失败监控脚本

在目标服务器上以 root 执行以下内容，即可生成脚本文件 `/opt/ssh_login_monitor.sh`。

```bash
cat >/opt/ssh_login_monitor.sh<<'EOA'
#!/bin/bash

LOG_FILE="/var/log/secure"   # CentOS/RHEL

tail -F "$LOG_FILE" | while read line; do
    if echo "$line" | grep -qE "Failed password|authentication failure|Invalid user"; then
        echo "[$(date)] SSH登录失败: $line"
    fi
done
EOA
```

生成后运行：

```bash
bash /opt/ssh_login_monitor.sh
```

说明：

- `/var/log/secure` 是 CentOS/RHEL 系的 SSH 日志；Debian/Ubuntu 上是 `/var/log/auth.log`。
- 匹配到 `Failed password`、`authentication failure`、`Invalid user` 任一关键词即输出一条记录。
- 当前写法只把结果打印到屏幕，未写入文件。
