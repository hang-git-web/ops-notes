# Linux 简介与 Xshell 连接

| 特点 | 说明 |
| --- | --- |

## 2. Linux 内核

- Linux 内核是 Linux 系统的**核心**，是 Linux 系统的**基石**，是 Linux 系统的**灵魂**。
- **操作系统 = 内核 + 程序**

```text
内核：管理硬件资源、进程调度、内存管理、文件系统等
程序：内核之上运行的各类应用软件
```

## 4. Xshell 安装与连接

### 安装

1. 从官网（xshell.com）下载 Xshell 8 Personal 个人免费版
2. 双击安装包，一路点击“下一步”完成安装

### 连接步骤

1. 在 Linux 虚拟机中获取 IP 地址：

```bash
ip addr
```

> 查看 `ens33`（或 `eth0`）对应的 `inet` 地址，例如 `192.168.232.131`。

2. 打开 Xshell，新建会话：

```text
名称：随便起，如 centos7
主机：192.168.232.131   （填上面查到的 IP）
端口：22
协议：SSH
```

3. 点击“连接”，首次连接弹窗**接受主机密钥**
4. 输入用户名（如 `root`）和密码，登录成功

> 提示：如果连接失败，先确认 IP 是否正确、`sshd` 服务是否在运行（`systemctl status sshd`）、防火墙是否放行 22 端口。
