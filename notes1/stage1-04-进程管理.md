# 进程管理基础

## 1. 什么是进程

- **进程是正在运行的程序实例**，是程序在系统中“活着”的状态。
- 简单理解：程序是硬盘上的静态文件，进程是它在内存中运行起来的动态过程。

## 2. 什么是进程 PID

- **PID（Process ID）** 是操作系统给每个进程分配的唯一编号，用来区分和管理进程。
- **PID 为 1 的进程一般是系统进程**（如 systemd / init），它是所有进程的祖先。

## 3. 进程四大状态

| 状态 | 说明 |
| --- | --- |
| Running | 运行中，正在使用 CPU |
| Sleeping | 睡眠中，等待事件或资源（最常见） |
| Zombie（僵尸） | 进程已结束，但父进程还没回收它的资源 |
| Stopped（停止） | 已停止，通常是暂停/挂起状态 |

## 4. 查看进程信息

> 详细内容可看 `notes` 目录下的 `stage1-06-进程管理.md`

补充命令：

```bash
pstree -p PID     # 查看以该 PID 为根的进程树
pstree -p 1       # 查看系统完整进程树
ps -ef            # 查看所有进程
top               # 动态查看进程信息
```

## 5. 进程控制

| 命令 | 作用 |
| --- | --- |
| `kill PID` | 结束指定进程 |
| `kill -9 PID` | 强制结束进程 |
| `nohup 命令 &` | 托管（托管厨房）：退出终端后进程仍继续后台运行 |

```bash
kill 1234                # 结束 PID 为 1234 的进程
kill -9 1234             # 强制结束进程

nohup bash backup.sh &   # 后台执行备份脚本，退出终端也不中断
```
